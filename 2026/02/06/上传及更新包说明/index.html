步骤 7：下载 zip 包（网盘取文件）

需要用 zip 包时，登录 GitHub 仓库页面：

  1. 进入 Newest-package-of-blog 仓库；
  2. 找到你上传的 blog-backup.zip（旁有「LFS」标识）；
  3. 点击文件 → 右上角「Download」，即可下载到本地。

关键说明（网盘使用注意）

  1. 免费版 Git LFS 每月有 1GB 存储 + 1GB 下载带宽，个人存博客 zip 包完全够用；
  2. 上传后，GitHub 仓库里的 zip 包和普通文件一样，可随时删除 / 替换（删除方法：仓库页面找到文件 → 右上角「…」→「Delete file」）；
  3. 若 zip 包＞5GB：拆分压缩包（比如拆成多个 4GB 的 zip）再上传。

总结

  1. 空仓库先「初始化提交 README」，解决「分支不存在」报错；
  2. 用 Git LFS 跟踪 zip 包，适配＞25MB 的大文件；
  3. 上传 / 下载步骤极简，完全能当「个人博客 zip 包网盘」用。

如果上传时遇到「网络超时」，切换手机热点再执行 git push 即可（国内访问 GitHub 偶尔抽风）。
